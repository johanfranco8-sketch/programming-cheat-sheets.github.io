Tipos esenciales

TypeScript suele inferir tipos correctamente. Añade anotaciones en límites del sistema: parámetros, respuestas públicas y datos externos.

const proyecto = "CodeSheets"; // string inferido
let visitas: number = 0;
const etiquetas: string[] = ["web", "guías"];

function saludar(nombre: string): string {
  return `Hola, ${nombre}`;
}
Evita any: usa unknown para datos todavía no validados y estrecha el tipo antes de operar.

Interfaces y alias

interface Usuario {
  readonly id: string;
  nombre: string;
  rol?: "admin" | "editor";
}

type Resultado<T> =
  | { ok: true; datos: T }
  | { ok: false; error: string };

Las propiedades opcionales usan ?; readonly impide reasignaciones accidentales. Los alias expresan uniones, intersecciones y tipos compuestos.

Uniones y narrowing

type Estado =
  | { tipo: "cargando" }
  | { tipo: "listo"; elementos: string[] }
  | { tipo: "error"; mensaje: string };

function renderizar(estado: Estado) {
  switch (estado.tipo) {
    case "listo": return estado.elementos.join(", ");
    case "error": return estado.mensaje;
    default: return "Cargando…";
  }
}

Una propiedad discriminante permite que el compilador conozca el caso exacto en cada rama.

Genéricos

Los genéricos preservan relaciones entre tipos sin duplicar código.

function primero<T>(elementos: T[]): T | undefined {
  return elementos[0];
}

interface Repositorio<T extends { id: string }> {
  obtener(id: string): Promise<T | null>;
  guardar(valor: T): Promise<void>;
}

Configuración recomendada

{
  "compilerOptions": {
    "target": "ES2022",
    "module": "ESNext",
    "strict": true,
    "noUncheckedIndexedAccess": true,
    "exactOptionalPropertyTypes": true
  }
}
  • Activa strict desde el inicio.
  • Valida datos de red o almacenamiento en tiempo de ejecución.
  • Genera tipos a partir del dominio, no de componentes visuales aislados.
  • Permite inferencia en variables locales y anota las fronteras públicas.
