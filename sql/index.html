SELECT y filtros

SELECT id, nombre, precio
FROM productos
WHERE activo = TRUE
  AND precio BETWEEN 10000 AND 50000
ORDER BY precio DESC
LIMIT 20;
  • Selecciona solo las columnas necesarias.
  • Usa IS NULL, no = NULL.
  • Combina condiciones con paréntesis cuando mezcles AND y OR.
  • Parametriza valores desde la aplicación; nunca concatentes entradas del usuario.

Agregaciones

SELECT categoria_id,
       COUNT(*) AS cantidad,
       AVG(precio) AS promedio,
       SUM(precio * existencias) AS inventario
FROM productos
WHERE activo = TRUE
GROUP BY categoria_id
HAVING COUNT(*) >= 5
ORDER BY inventario DESC;

WHERE filtra filas antes de agrupar; HAVING filtra los grupos resultantes.

JOIN

SELECT p.id, p.nombre, c.nombre AS categoria
FROM productos AS p
INNER JOIN categorias AS c ON c.id = p.categoria_id;

SELECT c.nombre, COUNT(p.id) AS productos
FROM categorias AS c
LEFT JOIN productos AS p ON p.categoria_id = c.id
GROUP BY c.id, c.nombre;

INNER JOIN

Devuelve coincidencias presentes en ambos lados.

LEFT JOIN

Conserva todas las filas de la tabla izquierda.

UPDATE productos
SET precio = precio * 1.05
WHERE activo = TRUE AND categoria_id = 3;

Seguridad: ejecuta primero el mismo WHERE con un SELECT y usa transacciones para cambios relacionados.

Diseño e índices

  • Define claves primarias, foráneas, restricciones y valores nulos conscientemente.
  • Normaliza para evitar duplicación; desnormaliza solo con evidencia y medición.
  • Crea índices para búsquedas y uniones frecuentes, considerando el costo de escritura.
  • Analiza el plan de ejecución antes de optimizar por intuición.
CREATE INDEX idx_productos_categoria_activo
ON productos (categoria_id, activo);

ALTER TABLE productos
ADD CONSTRAINT precio_no_negativo CHECK (precio >= 0);
