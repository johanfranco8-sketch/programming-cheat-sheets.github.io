Programa mínimo

public class Main {
    public static void main(String[] args) {
        String nombre = "CodeSheets";
        int guias = 10;
        System.out.printf("%s tiene %d guías%n", nombre, guias);
    }
}

Los tipos primitivos almacenan valores simples; las clases representan objetos. Usa nombres de clase en PascalCase y métodos o variables en camelCase.

Clases y objetos

public final class Producto {
    private final String nombre;
    private final long precio;

    public Producto(String nombre, long precio) {
        if (precio < 0) throw new IllegalArgumentException("Precio inválido");
        this.nombre = nombre;
        this.precio = precio;
    }

    public String nombre() { return nombre; }
    public long precio() { return precio; }
}
Encapsulación: conserva las invariantes dentro del constructor y expón el mínimo estado mutable.

Interfaces y polimorfismo

interface Notificador {
    void enviar(String destinatario, String mensaje);
}

class NotificadorEmail implements Notificador {
    @Override
    public void enviar(String destinatario, String mensaje) {
        System.out.println("Email para " + destinatario);
    }
}

Programa contra abstracciones cuando existan varias implementaciones o necesites sustituir colaboradores durante pruebas.

Colecciones y streams

List<Producto> productos = List.of(
    new Producto("Guía", 15000),
    new Producto("Pack", 35000)
);

List<String> nombres = productos.stream()
    .filter(p -> p.precio() > 20000)
    .map(Producto::nombre)
    .toList();

Excepciones y recursos

try (var lector = Files.newBufferedReader(Path.of("datos.txt"))) {
    String primeraLinea = lector.readLine();
    System.out.println(primeraLinea);
} catch (IOException error) {
    System.err.println("No se pudo leer: " + error.getMessage());
}
  • Usa try-with-resources para cerrar archivos, conexiones y streams.
  • No ocultes excepciones; resuélvelas, tradúcelas o propágalas.
  • Prefiere objetos inmutables cuando sea posible.
  • Prueba comportamiento público y casos límite.
