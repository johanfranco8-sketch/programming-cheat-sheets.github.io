Variables y tipos

Usa const por defecto y let cuando debas reasignar. JavaScript incluye valores primitivos y objetos; comprueba casos nulos explícitamente.

const nombre = "Ada";
let intentos = 0;
const activo = true;
const perfil = { nombre, activo };

const etiqueta = perfil?.nombre ?? "Sin nombre";

Funciones

Las funciones encapsulan comportamiento. Mantén entradas y salidas claras; evita depender innecesariamente del estado global.

function calcularTotal(precios, impuesto = 0.19) {
  const subtotal = precios.reduce((suma, precio) => suma + precio, 0);
  return subtotal * (1 + impuesto);
}

const duplicar = numero => numero * 2;
Consejo: una función pequeña con un nombre específico suele ser más sencilla de probar y reutilizar.

Arrays y objetos

Transformar

map() crea una colección con cada valor transformado.

Filtrar

filter() conserva elementos que cumplen una condición.

Acumular

reduce() combina la colección en un resultado.

const tareas = [
  { titulo: "Diseñar", lista: true },
  { titulo: "Probar", lista: false }
];
const pendientes = tareas.filter(tarea => !tarea.lista);
const titulos = tareas.map(({ titulo }) => titulo);

DOM y eventos

Selecciona el elemento, escucha el evento y modifica solo lo necesario. Usa delegación cuando muchos elementos comparten comportamiento.

const lista = document.querySelector("#tareas");

lista.addEventListener("click", evento => {
  const boton = evento.target.closest("button[data-id]");
  if (!boton) return;
  boton.closest("li")?.remove();
});

Módulos y asincronía

// api.js
export async function obtenerUsuarios() {
  const respuesta = await fetch("/api/usuarios");
  if (!respuesta.ok) throw new Error(`HTTP ${respuesta.status}`);
  return respuesta.json();
}

// app.js
import { obtenerUsuarios } from "./api.js";
try {
  const usuarios = await obtenerUsuarios();
  console.table(usuarios);
} catch (error) {
  console.error("No fue posible cargar", error);
}
  • Comprueba response.ok; fetch no rechaza automáticamente todos los errores HTTP.
  • Usa try/catch donde puedas responder o enriquecer el error.
  • Sirve módulos desde HTTP y declara type="module" en el script.
