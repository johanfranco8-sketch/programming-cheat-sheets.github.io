Cascada y selectores

La regla ganadora depende del origen, la importancia, la especificidad y el orden. Prefiere clases de baja especificidad y evita !important como solución habitual.

:root {
  --color-acento: #48e0af;
  --espacio: 1rem;
}

.tarjeta { padding: var(--espacio); }
.tarjeta__titulo { color: var(--color-acento); }
.tarjeta:hover { transform: translateY(-2px); }
Patrón: utiliza propiedades personalizadas para colores, espacios, tipografía y radios; facilitan cambios globales.

Modelo de caja

Cada elemento combina contenido, relleno, borde y margen. El ajuste global evita cálculos inesperados de ancho.

*, *::before, *::after { box-sizing: border-box; }

.panel {
  width: min(100%, 60rem);
  margin-inline: auto;
  padding: clamp(1rem, 3vw, 2rem);
  border: 1px solid #29415e;
  border-radius: 1rem;
}

Flexbox

Eje principal

justify-content distribuye elementos sobre el eje principal.

Eje transversal

align-items alinea los elementos en el eje perpendicular.

Reparto

flex, gap y flex-wrap controlan tamaño y salto.

.acciones {
  display: flex;
  align-items: center;
  justify-content: space-between;
  flex-wrap: wrap;
  gap: .75rem;
}

Grid

Grid organiza filas y columnas. auto-fit y minmax() permiten cuadrículas fluidas sin muchas consultas de medios.

.galeria {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(16rem, 1fr));
  gap: 1rem;
}
.destacada { grid-column: span 2; }

Diseño adaptable

  • Diseña primero para pantallas pequeñas y amplía cuando haya espacio.
  • Usa unidades relativas, min(), max() y clamp().
  • Evita alturas fijas para contenido textual.
  • Respeta prefers-reduced-motion al crear animaciones.
@media (min-width: 48rem) {
  .layout { grid-template-columns: 2fr 1fr; }
}
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after { scroll-behavior: auto; transition: none; }
}
