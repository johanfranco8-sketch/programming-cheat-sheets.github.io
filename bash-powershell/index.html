Bash y PowerShell

Opera archivos, encadena comandos y convierte tareas repetitivas en scripts reproducibles.

Navegación

Bash

pwd
ls -la
cd ~/proyectos
find . -type f -name "*.md"

PowerShell

Get-Location
Get-ChildItem -Force
Set-Location ~/proyectos
Get-ChildItem -Recurse -Filter *.md

Archivos y directorios

Bash

mkdir -p salida/reportes
cp archivo.txt copia.txt
mv copia.txt salida/
rm archivo-temporal.txt
cat datos.txt

PowerShell

New-Item salida/reportes -ItemType Directory -Force
Copy-Item archivo.txt copia.txt
Move-Item copia.txt salida/
Remove-Item archivo-temporal.txt
Get-Content datos.txt

Cuidado: verifica rutas antes de borrar, especialmente al usar recursión, comodines o privilegios elevados.

Pipes y filtros

Bash transporta principalmente texto; PowerShell transporta objetos con propiedades y métodos.

Bash

grep -R "TODO" src/ | sort | uniq
cat acceso.log | awk '{print $1}' | sort | uniq -c

PowerShell

Get-ChildItem src -Recurse |
  Select-String "TODO"

Get-Process |
  Where-Object CPU -gt 10 |
  Sort-Object CPU -Descending

Variables y condiciones

Bash

entorno="produccion"
if [[ -f ".env" ]]; then
  echo "Configuración encontrada"
fi
for archivo in *.md; do
  echo "$archivo"
done

PowerShell

$entorno = "produccion"
if (Test-Path .env) {
  Write-Host "Configuración encontrada"
}
Get-ChildItem *.md | ForEach-Object {
  $_.Name
}

Scripts robustos

Bash

#!/usr/bin/env bash
set -euo pipefail

origen="${1:-datos}"
[[ -d "$origen" ]] || { echo "No existe" >&2; exit 1; }
tar -czf respaldo.tar.gz "$origen"

PowerShell

param([string]$Origen = "datos")
$ErrorActionPreference = "Stop"

if (-not (Test-Path $Origen)) { throw "No existe" }
Compress-Archive -Path $Origen -DestinationPath respaldo.zip
  • Entrecomilla variables que representen rutas.
  • Devuelve códigos de salida útiles y mensajes por el canal apropiado.
  • No guardes credenciales dentro del script.
  • Prueba primero con datos temporales y operaciones no destructivas.
