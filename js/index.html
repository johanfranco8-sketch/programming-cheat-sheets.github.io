Estado predecible

export const estado = {
  tareas: [],
  filtro: "todas"
};

export function agregarTarea(texto) {
  const titulo = texto.trim();
  if (!titulo) return false;
  estado.tareas.push({ id: crypto.randomUUID(), titulo, lista: false });
  return true;
}
Flujo recomendado: evento → validación → actualización del estado → persistencia → render.

Render seguro del DOM

export function crearTarea(tarea) {
  const item = document.createElement("li");
  const texto = document.createElement("span");
  texto.textContent = tarea.titulo;

  const boton = document.createElement("button");
  boton.type = "button";
  boton.dataset.id = tarea.id;
  boton.textContent = "Completar";

  item.append(texto, boton);
  return item;
}

Para texto aportado por usuarios, usa textContent en vez de construir HTML con cadenas.

localStorage

const CLAVE = "codesheets-tareas";

export function guardar(tareas) {
  localStorage.setItem(CLAVE, JSON.stringify(tareas));
}

export function cargar() {
  try {
    const valor = JSON.parse(localStorage.getItem(CLAVE));
    return Array.isArray(valor) ? valor : [];
  } catch {
    return [];
  }
}
  • Almacena datos serializables, pequeños y no sensibles.
  • Valida la estructura recuperada; el almacenamiento puede estar vacío o alterado.
  • Versiona el esquema si esperas cambios futuros.
  • No uses localStorage para contraseñas, tokens críticos o información privada.

function filtrarTareas(tareas, filtro) {
  if (filtro === "pendientes") return tareas.filter(t => !t.lista);
  if (filtro === "listas") return tareas.filter(t => t.lista);
  return tareas;
}
