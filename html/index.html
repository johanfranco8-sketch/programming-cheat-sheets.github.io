Documento base

Todo documento comienza con el tipo HTML5, el idioma, los metadatos esenciales y un cuerpo visible.

<!doctype html>
<html lang="es">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Mi página</title>
</head>
<body>
  <h1>Contenido principal</h1>
</body>
</html>
Consejo: usa un solo h1 descriptivo y conserva una jerarquía de encabezados lógica.

Semántica

Regiones

header, nav, main, aside y footer describen la función de cada bloque.

Contenido independiente

article representa una pieza reutilizable; section agrupa contenido con un tema y encabezado.

Texto

Usa strong para importancia, em para énfasis y time para fechas legibles por máquinas.

<main>
  <article>
    <header><h2>Título</h2></header>
    <p>Contenido del artículo.</p>
  </article>
</main>

Enlaces, imágenes y tablas

  • Enlaces: escribe textos que expliquen el destino; evita “clic aquí”.
  • Imágenes: añade alt útil o déjalo vacío si la imagen es decorativa.
  • Tablas: reserva su uso para datos y agrega caption, encabezados y alcance.
  • Listas: usa ul cuando el orden no importe y ol para secuencias.
<figure>
  <img src="grafico.webp" alt="Ventas mensuales de enero a junio">
  <figcaption>Crecimiento durante el semestre.</figcaption>
</figure>

Formularios

Relaciona cada control con una etiqueta, selecciona el tipo de entrada correcto y valida tanto en el cliente como en el servidor.

<form action="/registro" method="post">
  <label for="email">Correo</label>
  <input id="email" name="email" type="email" autocomplete="email" required>

  <label for="rol">Rol</label>
  <select id="rol" name="rol">
    <option value="dev">Desarrollo</option>
    <option value="design">Diseño</option>
  </select>
  <button type="submit">Crear cuenta</button>
</form>

Accesibilidad y calidad

  • Declara el idioma y permite navegar con teclado.
  • No uses un div como botón; aprovecha los elementos nativos.
  • Mantén títulos únicos, nombres accesibles y mensajes de error comprensibles.
  • Valida el marcado y prueba con zoom, teclado y lector de pantalla.
