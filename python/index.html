Funciones y módulos

def calcular_total(precios: list[float], impuesto: float = 0.19) -> float:
    """Devuelve el total con impuesto."""
    return sum(precios) * (1 + impuesto)

if __name__ == "__main__":
    print(calcular_total([10_000, 25_000]))

Archivos y errores

from pathlib import Path
import json

ruta = Path("datos.json")
try:
    datos = json.loads(ruta.read_text(encoding="utf-8"))
except FileNotFoundError:
    datos = []
except json.JSONDecodeError as error:
    raise ValueError("El JSON no es válido") from error
  • Usa gestores de contexto o métodos de pathlib para administrar recursos.
  • Captura excepciones concretas, no un except vacío.
  • Agrega contexto al relanzar un error con raise ... from ....
  • Registra información útil sin exponer secretos.
